# System artwork

The 23 icons in `icons/` are original vector artwork distributed under the repository’s MIT license. They use a shared 64 × 64 viewBox and a neutral, high-contrast tile so they remain readable in Foundry’s light and dark themes. No external fonts, embedded bitmaps, scripts or network assets are required.

Equipment is identified by category and firearm family. Grenade payloads have separate fragmentation, smoke, flash and incendiary cues. Actions and hotbar macros use matching functional icons. Labels remain visible; artwork is not the only way to identify an item or action.

Character and NPC tokens keep Foundry’s default token icon. New items and compendiums receive category artwork. Sheets and chat replace old system placeholders at render time without editing existing world documents. Explicit custom artwork is preserved.

`fdern.svg` is retained for backwards compatibility with older worlds. It is no longer the default document image.
